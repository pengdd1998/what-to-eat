# 视觉方向卡 ×3（Stage 2 / design-directions）

> 依据：`docs/design/design-brief.md`（语境卡）。三方向在色彩体系、形态语言、字体气质、动效语言、插画策略五个维度中至少三维实质不同。
> 禁止清单已自查：无蓝紫渐变、无默认 Tailwind 脸、无 SaaS 后台、无通用衬线+无衬线组合、无 emoji 图标、无低对比灰字、无无意义浮动动效、无装饰性渐变滥用。

---

## 方向 A｜「深夜食堂灯」

一盏留到最后的灯：焦糖暖光打在深色桌面上，老板不问话，直接端上一碗。

- **色彩体系**：暖黑基底（近黑的焦褐 `#16120E`）＋ 琥珀暖光主色（`#F5A623` 系，像煲仔饭边缘的焦糖）＋ 米白文字（`#F2E8D5`）。单色温暖系，零渐变，语义红绿只用于反馈。暗色即本体，亮色＝"日间外带"衍生版。
- **字体气质**：中文超重黑体（HarmonyOS Sans / 思源黑体 Heavy）做菜名巨字——菜名就是海报；正文常规黑体；数字用 tabular。气质：锅气、厚实、不对仗。
- **形态与材质**：大圆角（16–20px"碗沿"）、卡片即碗；极淡的纸质纹理（2% 噪点，不抢戏）；高信息密度控制在一屏一焦点。
- **动效语言**：慢而暖。"端上桌"——结果卡自下而上 320ms ease-out 微过冲落定，配蒸汽一缕（CSS 绘制，2 秒消散）；按压器 1.02 回弹。尊重 reduced-motion（全静态）。
- **插画/图标**：粉笔菜单线条风（1.5px 单色描线小图标，暖白）；唯一的"插画"是揭晓时的蒸汽曲线。
- **参考意象**：深夜食堂的暖帘灯、砂锅揭盖的瞬间、木桌上一张手写菜牌。
- **贴合度论证**：耗竭基调（基调①②）要的是"被接住"——暖黑＋琥珀是视觉上的热汤；「今晚就它」揭晓时刻（品牌时刻①）由端菜动效＋蒸汽承载；「记得你」（基调④）体现在暖光常亮、界面不冷场；SSR 无 bundle（约束 4.4）下蒸汽纯 CSS 可达。
- **首屏速写**：
```
┌──────────────────────┐
│ ⏾ 吃什么        ⚙    │  ← 暖黑底，琥珀点睛
│                      │
│   今晚不用想了。      │  ← 超重黑体，米白
│   回答最多 3 题，      │
│   只给你一个答案。    │
│                      │
│ ╭──────────────────╮ │
│ │    开 吃 吧  →    │ │  ← 琥珀实心大按钮（碗沿圆角）
│ ╰──────────────────╯ │
│ 不想选？直接给我一个   │  ← 常驻兜底出口
└──────────────────────┘
```
- **做砸了会砸在哪**：暖棕系最容易失守对比度（4.5:1 红线）变成"脏"；蒸汽动效做廉价秒变屏保味；"深夜食堂"情怀泛滥会把工具拖成氛围博客。

## 方向 B｜「收口票据」

把决定印成一张裁定单：墨黑台面、朱红印章，落章即生效，概不退换。

- **色彩体系**：墨黑基底（`#101013` 冷黑，中性不偏暖）＋ 朱红印章色（`#E8442E`，唯一强调色）＋ 纸白（`#F5F2EA`）双元对立。全程零渐变、零阴影堆叠——靠墨/纸/章三色关系撑版面。
- **字体气质**：方形硬黑体（超大字重）＋ 等宽数字（步数、秒数、剩余次数全部等宽呈现，像票据编号）。气质：公文感×市井感。
- **形态与材质**：直角微圆（2–4px）；结果卡做成**裁切票据**——虚线打孔边、底部锯齿；「就吃这个」按下即"落章"（印章图形压印效果，非渐变）。
- **动效语言**：快而脆。票据打印上行动效（180ms ease-out，一次到位不回弹）；落章 120ms scale 1.15→1 落定＋轻微"顿挫"。全部 ≤200ms——快是人格。
- **插画/图标**：无插画。唯一图形资产是那枚朱红印章（"就它"二字篆刻感圆章）。图标用 2px 等线几何。
- **参考意象**：老式收银机撕票、菜市场小票、刻章铺、裁切线。
- **贴合度论证**：「收口者」人格（人格①）的最大化表达——票据＝终局，印章＝拍板，天然反"无限浏览"红线（约束 4.5）；等宽数字把「≤5 步 / 剩 2 次」的预算感做成视觉语言；30 秒预算（约束 4.3）与 ≤200ms 动效互为表里。风险侧：情绪温度最低。
- **首屏速写**：
```
┌──────────────────────┐
│ 吃什么........NO.0923 │  ← 票头，等宽编号
│=======================│
│  今晚的决定，          │  ← 方形硬黑体
│  交给我。              │
│                       │
│ ┌─ - - - - - - - -┐  │
│ │  答 3 题 · 30 秒  │  │  ← 票据卡，打孔虚线
│ └─ - - - - - - - -┘  │
│ ▓▓▓ 出 票 开 始 ▓▓▓  │  ← 墨黑按钮/朱红字
│ ~~~~~~~~ 直接给 ~~~~~ │  ← 锯齿边兜底出口
└──────────────────────┘
```
- **做砸了会砸在哪**：冷公文感最容易杀死「情绪化推荐语」（基调⑤）——菜名读出来没有锅气；朱红在暗底上控制不好变"警告色"；票据隐喻被做满（满屏锯齿/虚线）就成杂货。

## 方向 C｜「街角灯箱」

大排档灯箱翻牌的那一下：墨绿铁皮、芥末黄大字，热闹但只亮一块牌子。

- **色彩体系**：深墨绿基底（`#0F1F18`，夜里的铁皮绿）＋ 芥末黄主色（`#FFC53D`）＋ 辣椒红（`#FF5A3C`）单点亮 + 荧光青细线（`#3DDAD7`，仅描边辅助）。**多色但强纪律**：黄是唯一可做大色块的颜色，红/青限量出场。全部实色平涂，零渐变。
- **字体气质**：超粗标语体（黑体 Heavy + 字距紧），标题像灯箱招牌字；正文窄黑体。气质：吆喝感、市井活力。
- **形态与材质**：贴纸感——中圆角（12px）＋ 3px 实色描边（黄/白），像灯箱上贴的翻牌；铁皮质感用细噪点＋四角铆钉点（极简符号，不做拟物）。
- **动效语言**：弹而稳。结果=灯箱翻牌（rotateX 90°→0，240ms，尾段 8% 回摆）；按钮按压 scale 0.96；标签选中"啪"地亮起（背景瞬间填充，无渐隐）。spring 感但幅度克制，reduced-motion 全静态。
- **插画/图标**：平涂大色块食物剪影（灯箱画风格：一碗、一串、一锅，2–3 色平涂）——仅揭晓时刻出现，一屏最多一幅。
- **参考意象**：深夜大排档的灯箱菜单、旧式翻转站牌、夜市霓虹（取其"亮一块"不取其"满堂彩"）。
- **贴合度论证**：「情绪同伴＋锅气」（人格⑤）最足的方向——翻牌揭晓（品牌时刻①）的戏剧性最强；市井感与「一句情绪化推荐语」同频；墨绿底在暗光下比纯黑更"活"，契合"治愈"而不冷场。风险侧：热闹与低能量（基调②）存在张力，纪律失守即变吵。
- **首屏速写**：
```
┌──────────────────────┐
│ ▪吃什么…………… ⚙ │  ← 墨绿底+芥末黄字
│                      │
│ ┏━━━━━━━━━━━━━━┓    │
│ ┃ 纠结结束器      ┃    │  ← 3px 黄描边贴纸卡
│ ┃ 今晚它说了算    ┃    │
│ ┗━━━━━━━━━━━━━━┛    │
│                      │
│ ▛▀▀▀▀▀▀▀▀▀▀▜       │
│ ▌ 开 始 点 灯 ▐     │  ← 芥末黄大色块按钮
│ ▙▄▄▄▄▄▄▄▄▄▄▟       │
│  懒得选？翻牌直给      │
└──────────────────────┘
```
- **做砸了会砸在哪**：三色纪律一破就是夜市大杂烩；平涂食物剪影画不好就廉价；"热闹"过头直接背叛耗竭用户（基调①②），把收口工具做成打卡玩具。

## 维度对比表

| 维度 | A 深夜食堂灯 | B 收口票据 | C 街角灯箱 |
|---|---|---|---|
| 色彩体系 | 焦褐黑＋琥珀暖光，单色温暖系 | 冷墨黑＋朱红＋纸白，双色对立 | 墨绿＋芥末黄＋红/青点缀，多色强纪律 |
| 形态语言 | 大圆角 16–20px"碗沿"，纸纹，柔软 | 直角 2–4px，票据打孔，锐利 | 中圆角 12px＋3px 描边贴纸，铁皮 |
| 字体气质 | 超重黑体巨字菜名，锅气 | 方硬黑体＋等宽数字，公文×市井 | 超粗标语体，招牌吆喝 |
| 动效语言 | 慢暖（320ms 落定＋蒸汽），安慰感 | 快脆（≤200ms 打印/落章），果断感 | 弹稳（240ms 翻牌回摆），活力感 |
| 插画/图标 | 粉笔线条＋蒸汽一缕 | 零插画，唯一图形是朱红印章 | 平涂灯箱食物剪影（限量） |
| 情绪温度 | 高（治愈） | 低（笃定） | 中高（热闹） |
| 最大风险 | 对比度失守显"脏" | 杀死推荐语的锅气 | 三色纪律破功变吵 |

## 推荐

**推荐 A「深夜食堂灯」**。理由：语境卡的锚是"耗竭后的人要被接住"（基调①②）——A 是唯一把"暖"做成体系而不止是点缀的方向，且揭晓时刻（蒸汽＋端上桌）与「一句情绪化推荐语」天然同构；暗色第一公民在 A 里不是适配而是本体。**B 是强二号**：它对"收口者"人格与反无限浏览红线的表达最锋利，若你更看重"果断工具"而非"治愈同伴"，选 B。**C 的热闹与耗竭用户存在结构性张力**，除非你想赌"晚上也要精神一振"，否则不推荐。

**选择权在你。** 拍板后本卡连同理由（一句话）归档，进入阶段 3（设计系统规格）。

## 拍板记录（2026-09-03）

- **选定：C「街角灯箱」**。
- **拍板理由（本人原话）**：「选择C【街角灯箱】是因为虽然产品规划中估计晚餐时段使用率最高，但其实使用场景不特定在某个时间段，最好是界面主题能够跟随季节、时间甚至天气变化」。
- **对设计的影响（已入阶段 3 规格）**：C 从"夜间主题"升级为**主题系统**——灯箱结构语言（贴纸描边/翻牌/标语体/硬阴影）为不变层，色彩为可换"灯箱片"（时段×季节主题；天气项见语境卡 G7 未决）。原"亮色模式是否交付"（G6）被时段主题取代（清晨/午市=亮色片，夜间=暗色片，暗色仍为第一公民）。
