## 一、Design Tokens

### 1.1 色彩（暗色为第一公民）

```css
:root { /* 暗色（本体） */
  --bg-0: #0F1F18;      /* 墨绿铁皮底 */
  --bg-1: #14281F;      /* 卡片（贴纸面） */
  --bg-2: #1B3327;      /* 浮层/hover 面 */
  --bg-3: #24402F;      /* 按压/选中面 */

  --ink-1: #F2EFE6;     /* 主文字（纸白） 对 bg-0 ≈ 13.2:1 */
  --ink-2: #A8B5A3;     /* 次文字        对 bg-0 ≈ 6.5:1 */
  --ink-3: #6E8274;     /* 辅助说明/禁用（仅 ≥18px 或非文字场景） */

  --y: #FFC53D;         /* 芥末黄——唯一可做大色块的强调色 */
  --y-ink: #101A14;     /* 黄底上的文字/图标  对 --y ≈ 9.5:1 */
  --r: #FF5A3C;         /* 辣椒红——限负反馈/耗尽/错误点缀，禁止大面积 */
  --r-text: #FF8A6E;    /* 小字号错误文字（提亮版，对 bg-0 ≈ 6.2:1） */
  --c: #3DDAD7;         /* 荧光青——仅描边/焦点环/success，细线用 */

  --line: #2A4436;      /* 中性描边 */
  --focus: #3DDAD7;     /* 焦点环统一青色 */
}
:root[data-mode="light"] { /* 亮色衍生（日间外带；非默认） */
  --bg-0:#F3EFE4; --bg-1:#FBF8EF; --bg-2:#ECE7D8; --bg-3:#E2DCC9;
  --ink-1:#1A241E; --ink-2:#4C5A50; --ink-3:#8A968C;
  --y:#E0A816;          /* 亮底上黄加深，仅作标记/下划线，不做按钮底 */
  --r:#C93A22; --r-text:#B33018; --c:#0E8F88; --line:#D4CCB6; --focus:#0E8F88;
  /* 亮色模式主按钮改用 --ink-1 底 + --bg-0 字（黄底不达标） */
}
```

**色彩纪律（方向 C 的命）**：黄是唯一大色块；红每屏最多一处；青只做 2–3px 细线与焦点环；全站零渐变、零柔光阴影——立体感只来自**硬偏移阴影**与描边。

### 1.2 字体（零 Webfont，系统栈——首屏 ≤2s 预算的硬前提）

```css
--font-sans: -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans",
             "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
--font-mono: ui-monospace, "SF Mono", Menlo, Consolas, "Courier New", monospace;
```

| 层级 | 值 | 用途 |
|---|---|---|
| display-dish | 40px/1.15 w900，字距 0.01em | 菜名巨字（S6 主视觉） |
| display-slogan | 26px/1.3 w900 | S2 标语（招牌字） |
| h-quiz | 20px/1.4 w900 | 题干 |
| body | 16px/1.6 w400 | 正文/推荐语 |
| tag | 15px/1 w500 | 标签胶囊 |
| caption | 13px/1.5 w400 | 注释/免责 |
| num | 16px mono + `font-variant-numeric: tabular-nums` | 步数/秒数/剩余次数（票据编号感） |

灯箱标语技法：w900 ＋ 行首尾 `letter-spacing: .02em`；**禁止** text-shadow 描字（低渲染差异毁掉SSR一致性）。

### 1.3 间距（4px 网格）

`--s-1:4 --s-2:8 --s-3:12 --s-4:16 --s-5:20 --s-6:24 --s-8:32 --s-10:40`
屏边距 20px；卡片内距 16px；按钮组间距 12px；触达间距 ≥8px。

### 1.4 圆角/描边/阴影（贴纸语言）

```css
--r-card: 12px;  --r-btn: 12px;  --r-chip: 999px;
--bd-sticker: 3px solid;   /* 主卡片描边（黄/白） */
--bd-chip: 2px solid;      /* 标签描边 */
--shadow-pop: 0 4px 0 rgba(0,0,0,.55);   /* 硬偏移，贴纸厚度 */
--shadow-press: 0 1px 0 rgba(0,0,0,.55); /* 按压时位移配合 */
```

### 1.5 动效 token

| token | 值 | 用途 |
|---|---|---|
| --t-press | 90ms / cubic-bezier(.3,0,.7,.4) | 按压 scale .96 |
| --t-flip | 240ms / cubic-bezier(.2,.7,.3,1.12) | 灯箱翻牌（rotateX 90°→0，尾段 12% 回摆） |
| --t-lit | 60ms / linear | 标签选中瞬间填充（"啪"） |
| --t-fade | 160ms / ease-out | 推荐语整句淡入、视图切换 |
| --t-slide | 200ms / ease-out | 弹层进出 |
| --t-deal | 200ms / ease-out，逐张 +45ms（标签 +30ms） | 选项牌/标签发牌入场 |
| 蒸汽/灯泡闪 | 无 | C 方案无蒸汽；揭晓时"灯箱点亮"= 背景色 --bg-1→--bg-3 一次 60ms 切换 |

**红线**：`@media (prefers-reduced-motion: reduce)` 下所有 transition/animation 时长归 0（保留最终态，不闪白）。任何动效不得延长可交互时间（作答期间禁止阻塞式动画）。

### S1 隐私弹窗（FR-20/U8）★首触信任时刻
- 骨架：全屏遮罩＋Sheet 卡（描边纸白）；标题 w900「先说清楚我们收集什么」；三段正文 body；主按钮「知道了，开始」；免责 caption 常驻卡底。
- 四态：**默认**＝上述；**加载**＝无异步（SSR 随页出，规格：不设 loading）；**空**＝无（零数据展示是立场：本屏不出现任何数据行）；**错误兜底**＝JS 失效时 `<noscript>` 纯文本全文可达（合规底线：文案必须能读）。

### S2 首屏（FR-05/FR-11）★承接时刻「今晚它说了算」
- 骨架：顶部 mono 徽标行（`吃什么 · NO.yyyymmdd`）；标语 display-slogan；一行 caption（最多 3 题 · 30 秒 · 只给一个答案）；BtnPrimary「开始点灯」；Ghost 常驻「懒得选？翻牌直给」。
- 四态：**默认**如上；**加载**＝session/start 在途（≤2s）：标语即出（SSR），按钮呈"点灯中…"禁用态＋mono 计时点；**空**＝localStorage 不可用 → 自动内存 id，顶部细条 caption「本次只记得这一顿」（诚实降级）；**错误**＝start 失败 → StickerCard 错误卡「网打烊了，菜还在」＋BtnGhost 重试（不发生任何埋点上报）。

### S3 冷启动画像（FR-08）——单词卡闯关·三关连翻
- 骨架：居中纵排（.qwrap）——caption「先花 15 秒认识你（只需一次）」→ **Bulbs 关卡灯（1/3 亮）** → 题干 q-center w900 22px 居中 → **Flashcard 选项牌 3 列**（发牌入场）。选中即亮牌，320ms 后题卡 rotateX 翻入下一关；第三关选中自动翻入 S4 关 1。**无"下一步"按钮**（点击即作答，冷启动作答 3 击）。
- 四态：**默认**如上；**加载**＝无异步（boot 内联）；**空**＝boot 缺题 → 跳过画像直入 S4，顶部 caption「先按大众口味来」（服务端记 config 异常）；**错误**＝`cold-start` 204 失败 → 不阻断（impl §1.1 容错），底部细条「偏好没存上，不影响今晚」。

### S4 今晚问卷（FR-01/02/06）——两关（**全卷单选，owner 修订⑤ 2026-09-03：禁止平铺多选**）

> ⚠ 产品偏离登记：规划 FR-02 原文为「标签**多选**」；本修订按 owner 指令改为**单选**（选一个最讲究的）。收敛逻辑承担原多选的约束表达（画像已覆盖口味/汤水/辣度，单标签收口最讲究项）。**规划文档 FR-02 的回写待 owner 在规划侧确认**——设计轨按单选执行。

- **关 1 标签单选卡（自适应收敛）**：StickerCard「今晚最讲究什么？（关 1/2）」＋收敛标签单选小卡（3 列，规则同前：①冲突剔除 ②已知偏好预亮＝默认选中 ③收敛提示「已按你的口味收敛 · 选一个最讲究的，也可跳过」④空池直跳关 2）。交互：点卡即亮→420ms 自动翻关；**有预亮时**「下一关」按钮启用（确认默认选）；Ghost「不想选了？翻牌直给」常驻（FR-06）。

- 四态：**默认**如上；**加载**＝无；**空**＝标签池空（config 异常）→ 仅渲染关 2＋跳过出口，caption「今晚标签在补货」；**错误**＝answer 429 → toast「点太快啦，锅还没热。歇一秒。」；500 → toast「没记上这题，再点一下」（客户端重发幂等 client_event_id）。

## 三、情感化设计清单

### 微交互（反馈感全在"啪"和"顿"，不做飘）
1. 标签选中：60ms 硬填充（--t-lit）＋ 无缩放——像灯泡啪地亮。
2. 主按钮按压：translateY(3px)＋硬阴影 4px→1px——物理"按下去"。
3. 翻牌揭晓：rotateX 240ms 尾段 12% 回摆——灯箱翻牌的机械顿挫。
4. 换一剩余次数：mono 数字变化时旧数字 90ms 上移出、新数字上移入（禁滚动长动画）。
5. 负反馈点击：按钮文字即时变「记住了，下次绕开」＋红色描边退为 --line——收下不满的克制表达。

### 品牌时刻（语境卡 §五逐一落地）
- **揭晓「今晚就它」**（S6）：黄条点亮（60ms）→ 翻牌（240ms）→ 剪影随卡显现 → 推荐语整句淡入。总时长 ≤400ms，reduced-motion 全静态直出。
- **首屏承接「交给我」**（S2）：标语牌即首屏主视觉（StickerCard＋3px 黄描边）；「开始点灯」按钮文案与点灯隐喻闭环。
- **回访「它记得」**（S11）：**用昨晚真实菜名回填问句**——被记得从文案层兑现，而非视觉装饰。

### 文案语气规范（市井·麻利·诚实；禁：亲爱的/用户/亲～/抱歉给您带来不便）
- 加载：「翻牌中——好菜不过夜。」（>3s：「好菜不过夜，再等一秒。」）
- 空态（换一耗尽）：「今晚就这仨里挑了最配你的。」
- 错误（网络）：「网打烊了，菜还在。稍后再来。」／（429）：「点太快啦，锅还没热。歇一秒。」

## 四、无障碍与性能红线

- **对比度 ≥4.5:1**：正文/按钮对已核算（§1.1 注释值）；小字号错误文字用 `--r-text`；`--r` 原色仅 ≥20px w900 或图形。
- **触达 ≥44px**：主按钮 52px；标签命中垫 44px（视觉 32）；行间点按 ≥8px 间距。
- **reduced-motion**：全部动效归零保留终态；翻牌直出、秒表保留（文字非动画）。
- **性能**：零 Webfont、零位图（剪影为内联 SVG ≤2KB）、关键 CSS 内联 ≤14KB、JS 单文件 ≤15KB（原生，无库）；动效全 CSS transform/opacity（不触发 layout）；LCP＝菜名/标语文字。预算对齐：首屏 P75 ≤2s、等待态 ≤3s、302 ≤300ms（语境卡 §4.3 原值）。
- **读屏**：结果揭晓以 `aria-live="polite"` 播报菜名；四按钮均有 accessible name；focus 环统一 `--focus` 2px offset 2px，可见性不被描边吞没。

## 1.6 主题系统「灯箱片」（拍板理由落地：时间/季节自动换片）

**架构**：两层 token。结构层（不变）＝贴纸 3px 描边、12px 圆角、硬阴影厚度、翻牌动效、标语体、色彩纪律（一屏一大色块）。片层（可换）＝`data-theme` 属性切换的一组 CSS 变量。切换机制＝客户端本地时钟（零隐私、零请求、零 FOUC：变量内联在 `<head>`，秒级换片不重排布局）。

### 时段片（主轴，本地时钟自动切换；暗色片为默认与最打磨路径）

| 片 | 时段 | 地面 bg-0 | 卡面 bg-1 | 主色（唯一大色块） | 点缀 | 文字 ink-1 | 模式 |
|---|---|---|---|---|---|---|---|
| `evening` 晚市 | 17:00–21:00 | `#0F1F18` | `#14281F` | 芥末黄 `#FFC53D` | 辣椒红/荧光青 | `#F2EFE6` | 暗（默认） |
| `late` 深夜 | 21:00–05:00 | `#0B1411` | `#10201A` | 钠灯橙 `#FFA53C`（街灯钠光） | 暗青 `#2FA39B` | `#EFEAD9` | 暗 |
| `morning` 清晨 | 05:00–10:30 | `#F5F1E6`（豆浆纸白） | `#FBF8EF` | 现炸金 `#D98E04`（对白底大字/图形 ≥3:1；文字用 `#8A5A00`） | 油条红棕 `#B33018` | `#1A241E` | 亮 |
| `noon` 午市 | 10:30–17:00 | `#EFF2E4`（白炽豆绿） | `#F8FAEF` | 铁皮墨绿 `#1F4A38`（做按钮大色块，纸白字） | 番茄红 `#C93A22` | `#182420` | 亮 |

- 亮色片纪律：主色做色块时对底 ≥3:1（图形/大字），**正文永远用墨绿 ink**；按钮＝主色底＋暗字或墨绿底＋纸白字，二者对比均 ≥4.5:1。
- 换片动效：60ms 直切（--t-lit），不做渐变过渡——灯箱换片就是"啪"。

### 季节调制（副轴，由日期月份推导；调地面温度与点缀，不动主色与结构）

| 季 | 月份 | 调制 |
|---|---|---|
| 春 | 3–5 | 地面向青调 6%（`color-mix(in oklab, bg-0 94%, #3DDAD7)`）；点缀青升为次点缀 |
| 夏 | 6–8 | 地面向冷调 5%（混入 `#2FA39B`）；红点缀降饱和 10% |
| 秋 | 9–11 | 地面向暖调 7%（混入 `#D98E04`）；红点缀更醒目 |
| 冬 | 12–2 | 地面去暖提灰 5%；主色微降明度 4%（灯泡偏暗一档） |

实现：`data-season` 属性 ＋ `color-mix` 覆写三个地面变量；不支持 `color-mix` 的旧内核回退默认地面（渐进增强，不破布局）。

### 隐私与性能边界

- 时间/季节＝纯客户端 `Date`，**零网络、零位置、零埋点新增**（换片不记事件——它不是用户行为）。
- 主题对性能预算的影响＝零：全部是 CSS 变量，无额外请求、无重排（变量只改颜色）。
- 自动换片在身份页提供手动覆盖（演示/偏好），存储 `wte_theme_override`；恢复"跟随时间"一键可回。
