# ADR-005｜载体重评结论：全程 P-c（微信外 H5）＋M3 范围重定义

> 状态：**已接受（2026-09-03，本人拍板"执行选项 2"）**——ADR-002 载体重评（提前至 W1 触发，X5）就此闭合；U11 同步裁定为 c 变体。
> 拍板人：本人（ADR-002 §五既定持有人）；AI 提供证据链与选项分析（docs/execution/adr002-carrier-reeval-input.md）。

## 背景（关键事实）

- 无可用备案域：`.lifestyle` 不在工信部批复 TLD 白名单（永久不可备案）；本人确认无已备案主域可挂子域 → **P-a（微信内投放）无域名可用**
- 真机实测摩擦（2026-09-03）：微信文本不链接化 `.lifestyle`；微信扫码 → webview 拦截（安卓常无出口）；公共 DNS 有 1h 旧缓存窗口
- 新购可备案域＋备案＝2–4 周＋注册商/服务器条件 → 赶不上 M2（10/10）、勉强赶 M3（10/19）且烧窗口预算
- 业务目标＝8 周发布测试（验证假设），非规模化分发

## 候选方案

1. **P-c 全程＋M3 前备案**（保 M3 原设计）——被否：备案周期风险＋M3 前每周都在"等备案"状态；500 人公测的渠道转化价值在 n=30 队列上无法复现，为它押 2–4 周不值
2. **P-c 全程＋M3 重定义为定向回访研究（选定）**——零新增依赖，统计口径按既有 n=30 仿真参数重算
3. **微信群高摩擦分发实测**（二维码＋复制粘贴话术）——被否：回访 <20 条止损线大概率被摩擦击穿，数据周损失风险与 ADR-002 否决小程序的发布链逻辑同构

## 决策结果

1. 载体维持 ADR-002 之 E（H5）；`https://whattoeat.lifestyle` 为正式载体（caddy＋TLS 已上线）；**不启动备案**
2. 分发形态：M1＝本人浏览器/主屏图标；M2＝**面对面相机扫码＋即刻渠道**（同事场景天然适配）；微信仅作沟通渠道不作投放渠道
3. **M3 重定义**：500 人公测 → **M2 队列（10–30 人）深化＋回访加密度**；诚实假门、自报下单问句、北极星独立复算全部保留（跑在 M2 队列上）；公测放量（T3.2 规模部分）裁撤
4. 北极星判读不降级：规划 §4 的 MDE 参数本就按 n=30 设计（人均 ±0.1 次/周 ≈ 3 人改变行为），30 人×连续 2 周稳态＋逐人分布口径成立

## 理由（逐条对应背景）

1. 无备案域＝微信内路径物理不可行，非取舍问题
2. 业务目标是"统计结论是唯一交付物"（ADR-001/002 共同前提）——M3 换成 n=30 定向研究后，北极星/假门/自报下单三类核心证据仍可得，仅外推性受限（见后果）
3. 摩擦实测数据（不链接化/拦截/无出口）使选项 3 的止损风险可预判，不做无把握实验

## 否决理由

- 方案 1：[推测] 备案期间 M2 数据照常收集，但 M3 的 500 人渠道（U11 a/b）在无微信分发时本就依赖小红书/即刻付费导流——与"发布测试"目标错配，为规模付 2–4 周风险不对称
- 方案 3：摩擦数据不足一周就会触发回访止损，且损耗无法归因（产品问题 vs 分发问题）

## 后果

- **收益**：零外部依赖、零预算风险；本周即可全速进入 E1 收尾与 M1 狗粮；发布链/埋点/北极星口径全自主（ADR-002 选 E 的初衷完整兑现）
- **代价**：P5 结论限定于熟人/半熟人 cohort，**外推到公域用户的置信度下降**（付费意愿 ≥15% 在 n=30 的 CI ≈ ±13pp，只能方向性判读）；"公开测试"目标缩水为"定向研究"，M4 复盘需如实标注证据边界
- **新增风险与缓解**：①M2 队列礼节性使用偏差在无匿名公测对照时更难检测 → 回访抽样坚持非熟人 ≥8 人＋行为口径优先；②留存完全依赖主屏图标 → PWA 化（本次一并执行）＋ T0.6 浏览器标识实测（今晚开跑）监控回访入口

## 重新评估条件（信号或时间点）

1. M2 回访应答率 <60% [假设线] → 面对面/主屏入口有效性复审
2. M4 判 go 且下周期需要微信生态分发 → 备案路径重启（本 ADR 的方案 1 复活，域名须在已批复注册商购买）
3. 小程序复活条件不变（ADR-002 §四）
4. 微信放开新 gTLD 链接化/未备案域拦截政策变化 → 重评分发口径

## 修订一：正式主机名变更（2026-09-04 晚）

- **变更**：P-c 正式主机名由 whattoeat.lifestyle 改为 **chishenma.top**（腾讯云注册，DNSPod 解析，LE 证书已签，48 断言冒烟全绿）。
- **原因**：前任域名注册当日即遭注册商风控处置（order 取消＋账号 lock＋注册局委派摘除）。**P-c 决策本身不受影响**——载体形态（微信外 H5）、不备案立场、M3 重定义均不依赖具体域名；此事件反而实证了 X5「域名不可得」分支的真实性，处置路径（换域名而非换载体）验证了 P-c 的韧性。
- **教训（验证期域名选型三条，进发布检查单）**：①国内注册商＋国内支付（避开外卡×新账号×新 gTLD 反欺诈组合）；②一年期＋关闭自动续费；③注册后立即完成注册人邮箱验证。
- **遗留**：T0.6 标识实测序列重启（9/5–9/7）；A/B 二维码重生成（未对外投放，无泄露面）。
